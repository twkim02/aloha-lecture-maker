\begin{frame}{그래프 이론 \& DFS}{<Graph Theory \& DFS>}
  \begin{columns}[T]
    \column{0.42\textwidth}
      \vspace{2mm}
      \alert{인접 행렬}은 연결관계를 \hl{이차원 배열 형태}로 나타냅니다.\par\vspace{3mm}
      \texttt{g[i][j]=w} $\leftrightarrow$ $i$에서 $j$로 가는 간선의 가중치가 $w$이다.\par\vspace{4mm}
      \annot{양방향 그래프의 경우, 간선 $i{\leftrightarrow}j$가 $i{\to}j$, $j{\to}i$ 으로

        가중치가 없는 경우, $i{\to}j$의 간선이 있으면 \texttt{a[i][j]=1}, 없으면
        \texttt{a[i][j]=0}으로 나타냅니다.}

\begin{frame}[fragile]{그래프 이론 \& DFS}{<Graph Theory \& DFS>}
  \begin{twocol}
    그래프 외에서도 DFS를 활용할 수 있습니다. 옆은 배열에서 DFS를 사용하는 예시입니다.
    \par\vspace{4mm}
    일반적으로 DFS는
    \begin{enumerate}
      \item 현재 상태를 처리했다고 표시
      \item 될 수 있는 다음 상태 중에서 처리하지 않은 것에 대하여 반복
    \end{enumerate}
    의 구조를 가집니다.
  \colsplit
    \begin{minted}{cpp}
      int b[66][66];
      bool visited[66][66];
      int n;
      void dfs(int x, int y){
          visited[x][y] = true;
          int d = b[x][y];
          if(x + d < n && !visited[x + d][y])
              dfs(x + d, y);
          if(y + d < n && !visited[x][y + d])
              dfs(x, y + d);
      }
    \end{minted}
  \end{twocol}
\end{frame}
