\begin{frame}{BFS}{<복습 - 그래프>}
  \vspace{6mm}
  그래프를 표현하는 방식으로는 대표적으로 2가지가 있습니다.\par\vspace{2mm}
  \alert{인접 리스트(Adjacency List)}와 \alert{인접 행렬(Adjacency Matrix)}\par\vspace{5mm}
  \begin{itemize}
    \item 인접 리스트는 각각 정점들에 대해 간선으로 연결되어 있는 정점들을 각각의
      리스트로 표현하는 방식입니다.
    \item 인접 행렬은 $i$번 정점에서 $j$번 정점으로 가는 간선이 존재할 경우 행렬의
      $i$번째 행 $j$번째 열의 값을 1, 존재하지 않을 경우 0으로 설정해 표현하는 방식입니다.
  \end{itemize}
\end{frame}

\begin{frame}{BFS}{<BFS>}
  \vspace{8mm}
  \concept{BFS / Breadth-First-Search -- 너비 우선 탐색}
  \vspace{6mm}
  \begin{itemize}
    \item 너비 우선 탐색은 시작 정점으로부터 가장 인접한 정점을 먼저 탐색하는 방식입니다.
    \item 거리에 따라 단계별로 그 단계에 속하는 정점들을 방문한다고 생각하면 이해하기
      편할 수 있습니다.
  \end{itemize}
\end{frame}

\begin{frame}[fragile]{BFS}{<BFS>}
  \begin{twocol}
    \vspace{4mm}
    BFS를 구현해봅시다.\par\vspace{2mm}
    DFS와 다르게, BFS는 재귀적으로 구현하지 않고, \texttt{queue}를 사용해 비재귀적으로
    구현합니다.\par\vspace{2mm}
    \texttt{queue}가 FIFO 형태의 자료구조임을 생각해보면, 작동 방식을 이해하기 어렵지
    않을 것입니다.
  \colsplit
    \begin{minted}[fontsize=\footnotesize]{cpp}
      bool vis[1005];
      vector<int> edges[1005];
      void bfs(int start)
      {
          queue<int> q;
          vis[start] = 1;
          q.push(start);
          while (!q.empty())
          {
              int cur = q.front();
              cout << cur << ' ';
              q.pop();
              for (int &nxt : edges[cur])
              {
                  if (vis[nxt]) continue;
                  vis[nxt] = true;
                  q.push(nxt);
              }
          }
      }
    \end{minted}
  \end{twocol}
\end{frame}

  \begin{twocol}

\begin{frame}{BFS}{<BFS>}
  \vspace{8mm}
  \concept{DFS와 BFS의 시간 복잡도 -- \complexity{V + E}}
  \annot{(V = 정점의 개수, E = 간선의 개수)}
  \vspace{6mm}
  \begin{itemize}
    \item 모든 정점을 한번씩 방문하기 때문에 $V$
    \item 모든 정점에서 연결된 간선을 한번씩 체크하기 때문에 (방문 여부 체크 과정에서) $E$
  \end{itemize}
\end{frame}

  \subhead{문제 해설}
  \begin{itemize}
    \item $X$에서 $X{-}1$, $X{+}1$, $2X$로 갈 수 있다는 정보를 \alert{간선}으로 생각합시다.
    \item 이러한 그래프에서 $N$에서 $K$로의 최단 거리는 어떻게 구할 수 있을까요?
    \item 가중치가 없는 그래프에서는, \hl{BFS를 통해 최단 거리를 구할 수 있습니다.}
  \end{itemize}

\begin{frame}[fragile]{BFS}{<BFS>}
  \begin{twocol}
    \texttt{dist} 배열이 $-1$이라면 아직 방문하지 않음을, $-1$이 아니라면 시작점과의
    거리를 나타냅니다.\par\vspace{2mm}
    시작점인 $N$을 큐에 넣고 BFS를 시작합니다.\par\vspace{2mm}
    현재 정점이 \texttt{now}고, 연결된 정점 $x$를 아직 방문하지 않았다면, $x$의 거리는
    \texttt{now}의 거리보다 1 큽니다.\par\vspace{2mm}
    \texttt{dist[x] = dist[now] + 1}처럼 \texttt{dist} 배열을 업데이트하여, 시작점으로부터의
    거리를 저장합니다.
  \colsplit
    \begin{minted}[fontsize=\scriptsize]{cpp}
      int N, K;
      cin >> N >> K;
      for (int i = 0; i <= max(N, K) + 1; i++) dist[i] = -1;
      dist[N] = 0;
      queue<int> q;
      q.push(N);
      while (!q.empty())
      {
          int now = q.front();
          q.pop();
          if (now * 2 <= K + 1 and dist[now * 2] == -1)
          {
              dist[now * 2] = dist[now] + 1;
              q.push(now * 2);
          }
          if (now - 1 >= 0 and dist[now - 1] == -1)
          {
              dist[now - 1] = dist[now] + 1;
              q.push(now - 1);
          }
          if (now + 1 <= K + 1 and dist[now + 1] == -1)
          {
              dist[now + 1] = dist[now] + 1;
              q.push(now + 1);
          }
      }
      cout << dist[K];
    \end{minted}
  \end{twocol}
\end{frame}

\begin{frame}[fragile]{BFS}{<BFS>}
  \begin{twocol}
    도착 지점이 $K$이기 때문에, $K{+}1$보다 큰 위치로 갈 필요가 없습니다.\par\vspace{2mm}
    \annot{증명) $K$보다 큰 위치로 간다면, $K$에 도달하기 위해서 언젠가는 왼쪽으로
      이동해야 합니다. $\times 2$를 사용해 $K{+}2$ 이상으로 간 뒤 $-1$을 2번 이상 사용해
      $K$를 가는 것보다, $-1$을 먼저 사용한 후 $K$로 가는 것이 더 빠르기 때문입니다.}
    \par\vspace{2mm}
    비슷하게, 0보다 작은 위치로 갈 필요도 없습니다.\par\vspace{2mm}
    따라서 \texttt{now}의 범위를 확인하여 너무 많이 방문하지 않도록 효율성을 높여줄 수
    있습니다.
  \colsplit
    \begin{minted}[fontsize=\scriptsize]{cpp}
      int N, K;
      cin >> N >> K;
      for (int i = 0; i <= max(N, K) + 1; i++) dist[i] = -1;
      dist[N] = 0;
      queue<int> q;
      q.push(N);
      while (!q.empty())
      {
          int now = q.front();
          q.pop();
          if (now * 2 <= K + 1 and dist[now * 2] == -1)
          {
              dist[now * 2] = dist[now] + 1;
              q.push(now * 2);
          }
          if (now - 1 >= 0 and dist[now - 1] == -1)
          {
              dist[now - 1] = dist[now] + 1;
              q.push(now - 1);
          }
          if (now + 1 <= K + 1 and dist[now + 1] == -1)
          {
              dist[now + 1] = dist[now] + 1;
              q.push(now + 1);
          }
      }
      cout << dist[K];
    \end{minted}
  \end{twocol}
\end{frame}
